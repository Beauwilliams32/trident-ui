Roll out the Trident Studio brand system (docs/BRAND.md). New themes `trident-ui` (dark) and `trident-ui-light`: the brand's colour, Playfair Display / Inter / JetBrains Mono, radius, motion and shadows on the existing `--ui-*` names, with the 135 degree tile gradient as `--ui-accent-grad`. Adds the supplied tile and icon files to `brand/*` (tile, bleed, maskable, glyph, manifest, apple-touch, app-icon and favicon files), the dark and light lockups and the 1200 x 630 link-preview card, and self-hosts Playfair Display. The Depth Line mark stays, marked superseded. No existing theme, component or export changes value.
