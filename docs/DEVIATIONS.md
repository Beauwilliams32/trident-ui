# Deviations from docs/SPEC.md

Every place the package differs from the spec, or fills a gap the spec leaves open. Newest first.

| Date | Area | Spec | What we did | Why |
|---|---|---|---|---|
| 2026-10-11 | Increase Contrast | §9 contrast matrix; Apple HIG Increase Contrast | `tokens.json#high-contrast` generates per-theme `@media (prefers-contrast: more)` blocks (in `tokens.css` and each `themes/*.css`, after the palettes): ink, ink-2, muted and line-strong are mixed toward ink (ink toward white or black) in 1% steps until they meet 7, 8.5, 7 and 4.5:1 on bg, bg-2 and surface; line and glass-edge become the old line-strong; glass turns solid. Recorded as a minor change | No default colour role changes value; the overrides only apply to users who ask for more contrast, and only raise contrast. The changeset rule "contrast-affecting is major" was written for the default roles; the owner can still choose major at release. |
| 2026-10-11 | Touch targets | §9: 44px for primary actions on touch | Every interactive control gets an invisible 44x44 hit region under `(pointer: coarse)`. Three layout changes on touch only: text inputs grow from 40px to 44px (a hit region cannot be added to an `<input>` without one), fieldset options sit 20px apart, interactive chips take an 8px margin | Expanded regions must not overlap their neighbours or the extra area belongs to the wrong control (Material's touch-target wrapper does the same). Before any other visual change, all 48 desktop pages matched the old baselines (gate tolerance 0.1%), and at zero tolerance the only differing pixels (the paused Pause-motion button, one ±1 anti-aliased card corner) differ the same way on unchanged `main`. |
| 2026-10-11 | Menus are non-modal | Radix DropdownMenu and ContextMenu default to modal | `DropdownMenu` (prop `modal`, default false) and `ContextMenu` render non-modal | A modal Radix menu aria-hides the page while leaving it focusable, which axe reports as `aria-hidden-focus` (160 nodes). The WAI-ARIA menu-button pattern needs no modality; focus still moves in, Escape closes, focus returns. |
| 2026-10-11 | CommandPalette dialog | §7: cmdk 1.x | The palette is `cmdk`'s `Command` inside our own Radix Dialog, not `Command.Dialog` | `Command.Dialog` forwards no content props, so with no trigger Radix returned focus to nothing (`<body>`). `useReturnFocus` restores focus to whatever had it, for Dialog, Sheet and ConfirmDialog without a trigger too. |
| 2026-10-11 | Hero heading level | §7: "Hero requires a text H1" | `Hero` takes `level` (default 1) | A landing page keeps its H1; a hero embedded in docs or the gallery needs a lower level to keep one H1 per page. |
| 2026-10-11 | Gallery matrix | §10.6: every component × theme × reduced/pause × 360/1280 | 17 sections; `getting-started` and `tokens` are not pixel-snapshotted (15 × 48 = 720 baselines). Overlays are snapshotted closed; their open state is covered by `gallery/tests/keyboard.spec.ts` (axe on the open overlay, Escape, focus return) in a dark and a light theme | The two text-only sections are checked by `measure.spec.ts`, the contrast matrix and the gallery tests; their tall tables would add weight to every token change without catching anything those miss. An open modal over the page cannot share a screenshot with the rest of the section. |
| 2026-10-11 | `@trident/ui/app` budget | §9: app shell ≤180 kB gz including react-vendor | size-limit gates the whole entry with Radix and cmdk bundled at 51 kB gz (48.6 kB measured) | The first measurement + 5%, following the root-entry rule; consumers that tree-shake ship less. |
| 2026-10-11 | Playwright workers | none | `playwright.config.ts` runs 4 workers locally (CI default) and gives `expect` (screenshots included) 15s | The gate shares this Mac with other sessions (load average about 650 on 2026-10-11); at the default worker count 2 of 96 runs timed out on "element stable", then passed on rerun. |
| 2026-10-02 | 3D chunk headroom | §6.6, §9: lazy 3D chunk ≤250KB gz | `src/three/generated.ts` reads a precomputed per-theme/per-palette int table (`src/three/generated-colors.json`, written by `scripts/build-tokens.mjs`, pinned to tokens.json by `units.test.ts`) instead of resolving all of tokens.json at runtime. Measured: macOS 248.92 kB -> 246.57 kB; CI 250.14 kB -> 248.03 kB (PR #4 run 36998047757) | CI's first run on `main` (run 36735914426) measured the chunk at **250.14 kB** and failed `npm run size`, while macOS measured 248.92 kB. Same bundle; the gzip differs: CI's official Node 24 build ships Chromium's zlib, Homebrew Node on this Mac links system zlib 1.2.12, and the CI figure is about 0.5% larger. Dropping the token prose, primitives and runtime resolver from the payload leaves about 2 kB of headroom on CI (3.4 kB on macOS) without touching the spec budget or the drei root-import rule. |
| 2026-09-30 | Install is a plain fetch | §1: "`dist/` is committed on the tag, and there is no `prepare` script, so an install is just a tarball fetch" | The library build script is `build:lib`, not `build`, and `test/package.test.ts` bans every script name npm prepares on (`prepare`, `prepack`, `build`, `install`, `preinstall`, `postinstall`) plus `workspaces`. `v0.1.0` was cut with a `build` script and is not installable; `v0.1.1` is the first consumable tag | Having no `prepare` script is not enough: npm's git fetcher (pacote `lib/git.js`) also prepares on `build`. Preparation means `npm install --force --include=dev` in a temp clone (Playwright, three, the lot), and under npm 11.12.0 it fails outright (`git dep preparation failed: --prefer-online cannot be provided when using --prefer-offline`). Found by the v0.1.0 consumer-install proof. |
| 2026-09-28 | Gallery matrix | §10.6: every component × theme × light/dark × reduced/pause, 360 + 1280 | 12 themes × {reduced, paused} × {360, 1280} = 48 pages; one screenshot per group section (576 baselines, ~60MB). Each theme is shot in its **native** scheme only | Fleet light is deferred (§0.2) and no theme ships a second scheme, so "light/dark where applicable" is one scheme per theme (wmh-portal is the light one). |
| 2026-09-28 | Visual baselines | §10.6: local Chromium | Baselines are recorded on macOS (`__screenshots__/darwin/`); the visual spec skips on other platforms. CI (Linux) runs the gallery **axe** spec and size-limit only | Font rasterization differs per OS, so Linux runs could never match macOS baselines. |
| 2026-09-28 | axe rule set | §10.7 axe, WCAG 2.2 AA | `@axe-core/playwright` with tags wcag2a/aa, wcag21a/aa, wcag22a/aa. Best-practice rules (heading-order, landmark-one-main, region) are not gated | The gallery nests component examples that carry their own headings; the WCAG tags are the contract. |
| 2026-09-28 | motion-lite budget | §1: "about 2KB gz" | size-limit gates `initMotion()` at ≤3 kB gz (measured 2.76 kB) and the whole entry at ≤3.5 kB (3.09 kB), matching the motion group's own unit test | The port keeps the isCountable guard, Pause store and view-transition helper; still below the 07-motion.js it replaces (~2.8 kB). |
| 2026-09-28 | size-limit measurement | §9 budgets in KB gz | size-limit 14 with esbuild: minified + gzip, 1 kB = 1000 B. CSS is measured minified. React is always external; for the 3D chunk three, R3F and drei are **bundled** (size-limit would otherwise treat them as external peers) | Measures what a consumer actually ships. The 3D chunk was 248.9 kB of 250 kB (246.6 kB, 248.0 kB on CI, since 2026-10-02: see that row), almost all three core + R3F: any three bump must re-check it, and CI's gzip measures about 0.5% above macOS. |
| 2026-09-28 | Root-entry budget | none in spec | `@trident/ui` root entry gated at 11.9 kB gz (v0.1 measurement 11.3 kB + 5%) | §9 "CI fails on a bundle regression above 5%". |
| 2026-09-28 | Polymorphic `as` typing | none | Public `as?: ElementType` unchanged; render sites narrow to an internal `HtmlTag` type (`src/utils/poly.ts`) | @react-three/fiber 9 augments global `JSX.IntrinsicElements` (e.g. `line`), which collapsed polymorphic props to `never` once `feat/three` joined the program. |
| 2026-09-28 | Licence / visibility | §0.3-1, §1: public MIT repo | Repo was **private** when this was decided; `package.json` had `"private": true` and `"license": "UNLICENSED"` | Owner decision at the time: private for now, with public visibility as a later, separate decision. |
| 2026-09-28 | dist/ on main | §1: `dist/` committed on each tag | `dist/` is gitignored on `main` and force-added only on release commits/tags. `npm run check:dist` compares a committed dist/ to a fresh build on tags, and checks the build is byte-deterministic elsewhere | Keeps main free of stale builds while meeting the tag contract. |
| 2026-09-28 | Root entry | Task: root index re-exports every group | `@trident/ui` re-exports a11y, layout, type, actions, forms, display, feedback, utils. `server`, `islands`, `motion-lite`, `motion`, `app`, `three` are **subpath entries only** | Their optional peers (three, R3F, motion, Radix, cmdk, sonner) or server-only code must never enter a client bundle that imports the root. Enforced by `no-restricted-imports` in eslint.config.js. |
| 2026-09-28 | Toolchain | TypeScript (latest) + tsup | TypeScript 6.0.3; `tsconfig.build.json` sets `"ignoreDeprecations": "6.0"` | tsup 8.5.1's DTS build injects `baseUrl`, which TS 6 rejects (TS5101) without it. Remove when tsup drops `baseUrl`. |
| 2026-09-28 | Versions | React 19.3, Vite 8, Vitest 4, three 0.180.0, R3F 9.8, drei 10, motion 13 | Installed exactly: react/react-dom 19.3.0, vite 8.3.1, vitest 4.1.11, tsup 8.5.1, three 0.180.0, @react-three/fiber 9.8.1, @react-three/drei 10.7.9, motion 13.4.4, vitest-axe 0.1.0, jsdom 30.1.1 | All exist; no substitution needed. |
| 2026-09-28 | ensureContrast | §2.3: pick on-accent, derive accent-text, clamp fills < 3:1 | Also nudges the fill (never below 3:1 on bg) until `on-accent` reaches 4.5:1 | §9 requires on-accent on accent >= 4.5:1. Ops' default `#6366f1` reaches only 4.47:1 with white otherwise. |
| 2026-09-28 | Roles the spec leaves open | §3 gives no `line-strong`, `surface-raised`, `bg-2` for some themes, or status colours for light themes | Chosen values in tokens.json (e.g. fleet `line-strong #5a7591`, wmh-portal status `#047857/#b54708/#b91c1c/#1d4ed8`), each passing the §9 matrix | Needed for the contrast matrix; no spec value was changed. **No spec colour failed the matrix**, so no `accent-text` adjustment was required. |
